# Excel-Sales-Dashboard
An interactive Sales Analysis Dashboard built in Microsoft Excel to analyze Superstore sales performance across regions, years, categories, customers, and shipping modes. The dashboard provides business insights through dynamic visualizations, KPI cards, Pivot Tables, Pivot Charts, Slicers, and Data Modeling.
